# test_repo

Java のお試し用プロジェクトです。ビルドツール（Maven / Gradle）を使わない最小構成で、
Swing による GUI アプリ（ウィンドウが起動するアプリ）の基本を確認できます。

実行するとコンソールではなく **GUI ウィンドウ** が立ち上がります。

## ディレクトリ構成

```
.
├── README.md
├── .gitignore
└── src
    └── Main.java   # Swing の GUI アプリ本体
```

## 必要なもの

- JDK 11 以上（`java -version` と `javac -version` で確認できます）
- GUI を表示できる環境（デスクトップ環境）

## 実行方法

### 1. コンパイルしてから実行する（基本の手順）

```bash
javac src/Main.java   # コンパイル（src/Main.class が生成されます）
java -cp src Main     # 実行（ウィンドウが開きます）
```

`-cp src` は「クラスファイルを探す場所（クラスパス）に src を指定する」という意味です。

日本語が文字化けする場合は、文字コードを明示してコンパイルしてください。

```bash
javac -encoding UTF-8 src/Main.java
```

### 2. コンパイルせずに直接実行する（Java 11 以上）

Java 11 以上であれば、1 ファイルのプログラムは次のように直接実行できます。

```bash
java src/Main.java
```

この場合 `.class` ファイルは生成されません。手軽に試したいときに便利です。

## 画面の流れ

1 つのウィンドウ（`JFrame`）の中で、`CardLayout` を使って 2 つの画面を切り替えます。

```
入力画面 --「決定」（入力チェック OK）--> 表示画面 --「戻る」--> 入力画面
```

- **入力画面**: 説明ラベル、入力欄（`JTextField`）、「決定」ボタン
- **表示画面**: `Hello World! <入力値>` を表示するラベル、「戻る」ボタン

例: 入力欄に `こんにちは` と入力して「決定」を押すと、表示画面に
`Hello World! こんにちは` と表示されます。

## 入力ルール

入力できるのは **全角** の次の文字だけです。

| 種類 | Unicode の範囲 | 例 |
| --- | --- | --- |
| ひらがな | U+3040〜U+309F | あいう |
| カタカナ | U+30A0〜U+30FF | アイウ |
| 漢字（CJK 統合漢字） | U+4E00〜U+9FFF | 漢字 |
| 全角数字 | U+FF10〜U+FF19 | ０１２ |
| 全角英字（大文字） | U+FF21〜U+FF3A | ＡＢＣ |
| 全角英字（小文字） | U+FF41〜U+FF5A | ａｂｃ |

上記以外はすべてエラーになります。

- 半角文字（`abc`、`123`、半角カナなど）はエラー
- 全角・半角の記号（`！`、`、`、`?` など）はエラー
- 空白（全角スペース含む）はエラー
- 何も入力しない（空文字）もエラー

## エラー時の動き

入力チェックに失敗した場合は画面遷移せず、入力画面のまま
**入力欄の背景色が赤（薄い赤）になり**、エラーメッセージが表示されます。

正しい値を入れ直して「決定」を押すと、背景色は通常色（白）に戻り、表示画面へ遷移します。
「戻る」ボタンで入力画面に戻ったときも、背景色は通常色に戻ります。
